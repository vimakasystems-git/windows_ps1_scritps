# Android: celulares e tablets

Código compartilhado: ../../mobile/www. Compile com Java 17, Android SDK 36 e Gradle 8.11.1: `gradle assembleDebug`.

O APK debug é exclusivo para testes. Antes de distribuir uma versão de produção, configure uma chave persistente de assinatura fora do Git. Consulte [limites e instruções](../../mobile/README.md).
